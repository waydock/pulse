# @waydock/pulse-core

Shared types and the config/heartbeat schema (zod) for
[`@waydock/pulse`](https://www.npmjs.com/package/@waydock/pulse).

This package is the contract layer: the `Config` schema for `pulse.config.yaml`,
the `HeartbeatPayload` / `AgentStatus` / `Metrics` types, and the `NodeRecord`
type. It has no runtime side effects.
