# Pulse v1 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pulse v1 — a public OSS agent (`@waydock/pulse`) that watches AI-agent boxes and POSTs heartbeats, plus a multi-tenant receiver built inside waydock that detects host-level silence off-box and pages the owner.

**Architecture:** Two public npm packages (`@waydock/pulse-core` contract, `@waydock/pulse` CLI) + a shared internal `@waydock/pulse-server` package + a separate `pulse-ingest` Vercel project + receiver surfaces inside the main waydock app. Liveness is receiver-arrival-time + per-node deadline in a global Redis ZSET; a durable Postgres `pulse_nodes` registry means a dead box never vanishes; a per-minute sweep + periodic reconciliation detect silence and deliver alerts through a `pulse_alerts` outbox.

**Repo layout (confirmed 2026-06-11):**
- `github.com/waydock/waydock-pulse` (public) — `packages/core/` (`@waydock/pulse-core`), `packages/agent/` (`@waydock/pulse`)
- `github.com/waydock/waydock` (private, npm workspaces monorepo) — `packages/pulse-server/` (`@waydock/pulse-server`), `apps/pulse-ingest/` (separate Vercel project → `ingest.waydock.ai`), root app (`waydock.ai/pulse` dashboard + auth + billing)
- Prisma schema + migrations owned by the root waydock app; `pulse-ingest` shares the same generated `@prisma/client` via workspace hoisting (root `postinstall` runs `prisma generate`)

**Tech Stack:** TypeScript, zod, Node (agent), Next.js 16 App Router + Prisma 7 + Postgres (RLS) + Upstash Redis + Resend + Stripe (receiver), vitest. Spec: `docs/superpowers/specs/2026-06-04-pulse-design.md` — read it before starting; every task references it.

```ts
/** Unix SECONDS sanity bound: reject ms-scale values. 10_000_000_000 ≈ year 2286. */
const unixSeconds = z.number().int().nonnegative().max(10_000_000_000)

  uptime: z.number().nonnegative(),

export const HeartbeatPayload = z.object({
  node: z.string().min(1).max(128),
  ts: unixSeconds,
  interval: z.number().int().positive().max(86_400),
  agents: z.array(AgentStatus).max(100),
  metrics: Metrics,
```

```ts
// Exactly one of process|http|command per check (a check is one signal).
const Check = z.union([
  z.object({ process: z.string().min(1) }).strict(),
  z.object({ http: z.string().url() }).strict(),
  z.object({ command: z.string().min(1) }).strict(),
])
export type Check = z.infer<typeof Check>

const Defaults = z.object({
  retries: z.number().int().min(0).max(20).default(3),
  confirm: z.number().int().min(1).max(10).default(2),
  interval: z.number().int().positive().max(86_400).default(60),
}).default({})

const AgentConfig = z.object({
  name: z.string().min(1).max(64),
  group: z.string().min(1).max(64).optional(),
  checks: z.array(Check).min(1).max(10),
  // string command, or false = alert-only (monitor, never auto-restart)
  restart: z.union([z.string().min(1), z.literal(false)]).optional(),
  retries: z.number().int().min(0).max(20).optional(),  // overrides defaults.retries
  confirm: z.number().int().min(1).max(10).optional(),
})

export const Config = z.object({
  node: z.string().min(1).max(128),
  heartbeat: z.object({
    url: z.string().url(),
    key: z.string().optional(),  // optional: may come from ~/.pulse/credentials.json
    interval: z.number().int().positive().max(86_400).default(60),
  }),
  webhook: z.object({ url: z.string().url() }).optional(),
  defaults: Defaults,
  agents: z.array(AgentConfig).min(1),
  metrics: z.object({ cpu: z.boolean(), mem: z.boolean(), disk: z.boolean() }).partial().default({ cpu: true, mem: true, disk: true }),
})
```

## Chunk 2: `@waydock/pulse-server` — Store, notifier, gate

The shared internal package both deployments import (spec §3, §5). Heart of the system. Tenant-aware `Store` seam composing **Postgres `pulse_nodes` registry ⊕ Redis hot state**. Logic is tested against an `InMemoryStore` (fast, deterministic); a thin contract test pins the real `PgRedisStore` against Upstash.

> **DESIGN CORRECTION (plan-review fix) — the alert episode lives in the durable outbox, NOT a Redis flag.**
> The first draft kept an `alerted` boolean inside the Redis snapshot with a Lua CAS. That is wrong: string-matching
> JSON is fragile, and the flag is lost when the snapshot TTL expires — silently missing a recovery alert for a
> long-dead box. **Single source of truth for "is this node in an open silent episode" = a `pulse_alerts` row with
> status `open`,** with a partial unique index `UNIQUE (organization_id, node_id) WHERE status='open'` making
> "open an episode" atomic + exactly-once. The Store therefore exposes `openAlertEpisode(orgId,id)` → `{opened}`
> (true only the first time) and `closeAlertEpisode(orgId,id)` → `{closed}`. `recordHeartbeat`'s `recovered` IS
> `closeAlertEpisode().closed`. **No Redis `alerted` flag, no `ALERTED_CAS` Lua.** `NodeRecord.alerted` (display
> only) is derived = "an open episode exists". This survives snapshot expiry and removes the same-tick race.
> Grace is floored at the 60s sweep tick (spec §4.3): `grace = max(grace, 60)` inside `computeDeadline`.
> `InMemoryStore`/`PgRedisStore` reconciliation re-derives from the registry's throttled `lastSeen + period + grace`.

```ts
// src/store/deadline.ts
import type { AgentStatus, NodeStatus } from '@waydock/pulse-core'
export const INTERVAL_CEILING = 3600
export function clampInterval(reported: number, planFloor: number): number {
  return Math.min(INTERVAL_CEILING, Math.max(planFloor, reported))
}
export function computeDeadline(arrivalTs: number, clampedInterval: number, grace: number, sweepTick = 60): number {
  return arrivalTs + clampedInterval + Math.max(grace, sweepTick)  // grace floored at the sweep tick (spec §4.3)
}
export function classifyStatus(n: { lastSeen: number | null; deadline: number; agents: AgentStatus[] }, now: number): NodeStatus {
  if (n.lastSeen == null) return 'pending'
  if (n.deadline < now) return 'down'
  return n.agents.some(a => a.status === 'down') ? 'degraded' : 'up'
}
```

```ts
import type { HeartbeatPayload, NodeRecord } from '@waydock/pulse-core'
export interface RecordResult { recovered: boolean }
export interface Store {
  /** Registry-first then hot. arrivalTs = receiver now (sec). planFloor from caller's cached entitlement. */
  recordHeartbeat(orgId: string, p: HeartbeatPayload, arrivalTs: number, planFloor: number, grace: number): Promise<RecordResult>
  getNode(orgId: string, id: string): Promise<NodeRecord | null>
  listNodes(orgId: string): Promise<NodeRecord[]>            // registry LEFT JOIN hot
  countNodes(orgId: string): Promise<number>                // active (non-paused) registry rows
  findOverdue(nowTs: number): Promise<NodeRecord[]>          // ACROSS orgs, deadline < now, excludes paused
  openAlertEpisode(orgId: string, id: string): Promise<{ opened: boolean }>   // atomic insert-if-none (partial unique idx); opened:true only first time
  closeAlertEpisode(orgId: string, id: string): Promise<{ closed: boolean }>  // on recovery; closed:true iff an open episode existed
  pauseNode(orgId: string, id: string): Promise<void>       // billing downgrade: ZREM, keep registry row
  deleteNode(orgId: string, id: string): Promise<void>
  reconcile(nowTs: number, grace: number): Promise<NodeRecord[]>  // registry rows missing from hot, past deadline
}
```

```ts
import { describe, it, expect, beforeEach } from 'vitest'
import { InMemoryStore } from './in-memory.js'
import type { HeartbeatPayload } from '@waydock/pulse-core'

const hb = (node: string, agentsUp = true): HeartbeatPayload => ({
  node, ts: 1000, interval: 60,
  agents: [{ name: 'a', status: agentsUp ? 'up' : 'down', restarts: 0 }],
  metrics: { cpu: 1, mem: 1, disk: 1, load1: 0, uptime: 1 },
})

describe('InMemoryStore', () => {
  let s: InMemoryStore
  beforeEach(() => { s = new InMemoryStore() })

  it('records a heartbeat: creates registry row + hot state, lastSeen = arrivalTs not agent ts', async () => {
    await s.recordHeartbeat('o1', hb('n1'), 5000, 60, 60)
    const n = await s.getNode('o1', 'n1')
    expect(n?.lastSeen).toBe(5000)          // arrival, NOT 1000
    expect(n?.clientTs).toBe(1000)
    expect(n?.deadline).toBe(5000 + 60 + 60)
    expect(n?.firstSeen).toBe(5000)
  })

  it('clamps a too-fast interval to the plan floor in the deadline', async () => {
    await s.recordHeartbeat('o1', { ...hb('n1'), interval: 10 }, 5000, 300, 60)
    expect((await s.getNode('o1', 'n1'))?.deadline).toBe(5000 + 300 + 60)
  })

  it('findOverdue returns nodes past deadline across orgs, excludes paused', async () => {
    await s.recordHeartbeat('o1', hb('dead'), 1000, 60, 60)   // deadline 1120
    await s.recordHeartbeat('o2', hb('live'), 9000, 60, 60)   // deadline 9120
    const overdue = await s.findOverdue(5000)
    expect(overdue.map(n => n.id)).toEqual(['dead'])
    await s.pauseNode('o1', 'dead')
    expect(await s.findOverdue(5000)).toHaveLength(0)
  })

  it('openAlertEpisode is exactly-once; recordHeartbeat recovers iff an episode was open', async () => {
    await s.recordHeartbeat('o1', hb('n1'), 1000, 60, 60)
    expect((await s.openAlertEpisode('o1', 'n1')).opened).toBe(true)   // first open
    expect((await s.openAlertEpisode('o1', 'n1')).opened).toBe(false)  // already open
    const r = await s.recordHeartbeat('o1', hb('n1'), 6000, 60, 60)     // beat closes the episode
    expect(r.recovered).toBe(true)
```

```ts
// src/store/in-memory.ts
import type { HeartbeatPayload, NodeRecord } from '@waydock/pulse-core'
import type { Store } from './store.js'
import { clampInterval, computeDeadline } from './deadline.js'

// `lastSeen`/`expectedPeriod` are mirrored on the registry (throttled in Postgres) so reconciliation works
// even after the hot snapshot expires. `openEpisode` is the durable alert-episode flag (Postgres pulse_alerts).
type Reg = { organizationId: string; id: string; firstSeen: number; lastSeen: number | null; expectedPeriod: number; paused: boolean; visibility: 'org' | 'private'; openEpisode: boolean }
type Hot = { lastSeen: number; clientTs: number; expectedPeriod: number; deadline: number; agents: NodeRecord['agents']; metrics: NodeRecord['metrics'] }

export class InMemoryStore implements Store {
  private reg = new Map<string, Reg>()
  private hot = new Map<string, Hot>()
  private key(o: string, id: string) { return `${o}:${id}` }

  async recordHeartbeat(orgId: string, p: HeartbeatPayload, arrivalTs: number, planFloor: number, grace: number) {
    const k = this.key(orgId, p.node)
    const period = clampInterval(p.interval, planFloor)
    if (!this.reg.has(k)) this.reg.set(k, { organizationId: orgId, id: p.node, firstSeen: arrivalTs, lastSeen: arrivalTs, expectedPeriod: period, paused: false, visibility: 'org', openEpisode: false })
    const r = this.reg.get(k)!
    r.paused = false; r.lastSeen = arrivalTs; r.expectedPeriod = period   // registry mirror (throttled in PgRedisStore)
    const deadline = computeDeadline(arrivalTs, period, grace)
    this.hot.set(k, { lastSeen: arrivalTs, clientTs: p.ts, expectedPeriod: period, deadline, agents: p.agents, metrics: p.metrics })
    const { closed } = await this.closeAlertEpisode(orgId, p.node)         // a beat ends any open silent episode
    return { recovered: closed }
  }
  private join(r: Reg): NodeRecord {
    const h = this.hot.get(this.key(r.organizationId, r.id))
    return { organizationId: r.organizationId, id: r.id, firstSeen: r.firstSeen, paused: r.paused, visibility: r.visibility,
      lastSeen: h?.lastSeen ?? null, clientTs: h?.clientTs ?? null, expectedPeriod: h?.expectedPeriod ?? r.expectedPeriod,
      deadline: h?.deadline ?? 0, alerted: r.openEpisode, agents: h?.agents ?? [], metrics: h?.metrics ?? null }
  }
  async getNode(o: string, id: string) { const r = this.reg.get(this.key(o, id)); return r ? this.join(r) : null }
  async listNodes(o: string) { return [...this.reg.values()].filter(r => r.organizationId === o).map(r => this.join(r)) }
  async countNodes(o: string) { return [...this.reg.values()].filter(r => r.organizationId === o && !r.paused).length }
  async findOverdue(now: number) {
    return [...this.reg.values()].filter(r => !r.paused).map(r => this.join(r))
      .filter(n => n.lastSeen != null && n.deadline < now)
  }
  async openAlertEpisode(o: string, id: string) {
    const r = this.reg.get(this.key(o, id)); if (!r || r.openEpisode) return { opened: false }
    r.openEpisode = true; return { opened: true }                          // PgRedisStore: INSERT ... ON CONFLICT DO NOTHING on the partial unique idx
  }
  async closeAlertEpisode(o: string, id: string) {
    const r = this.reg.get(this.key(o, id)); if (!r || !r.openEpisode) return { closed: false }
    r.openEpisode = false; return { closed: true }                          // PgRedisStore: UPDATE pulse_alerts SET status='resolved' WHERE ... status='open'
  }
  async pauseNode(o: string, id: string) { const r = this.reg.get(this.key(o, id)); if (r) r.paused = true; this.hot.delete(this.key(o, id)) }
  async deleteNode(o: string, id: string) { this.reg.delete(this.key(o, id)); this.hot.delete(this.key(o, id)) }
  async reconcile(now: number, grace: number) {
    const out: NodeRecord[] = []
    for (const r of this.reg.values()) {
      if (r.paused || r.lastSeen == null) continue
      const h = this.hot.get(this.key(r.organizationId, r.id))
      if (!h) { // lost hot state: re-derive deadline from the registry's throttled lastSeen + period + grace (spec §5)
        const deadline = computeDeadline(r.lastSeen, r.expectedPeriod, grace)
        if (deadline < now) { this.hot.set(this.key(r.organizationId, r.id), { lastSeen: r.lastSeen, clientTs: r.lastSeen, expectedPeriod: r.expectedPeriod, deadline, agents: [], metrics: null }); out.push(this.join(r)) }
      }
    }
    return out
  }
  // test-only seams
  _expireHot(o: string, id: string) { this.hot.delete(this.key(o, id)) }
  _dropFromDeadlineIndex(o: string, id: string) { this.hot.delete(this.key(o, id)) }
}
```
